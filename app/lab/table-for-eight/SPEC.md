# Table for Eight (/lab/table-for-eight)

**Idea:** the supper club seen from above. The home page is a set table; each section has a place.

**Palette (evening):** cloth #17352A (page), linen #F1EEE6 (cards), candle #F6B94F (flame, focus ring), claret #7C2236 (wine, buttons, links on linen), sage #A9C3AE (secondary text on cloth), wax #FFF8EA (headings on cloth). Helpers: cloth-deep, cloth-lift, ink-soft #3F5547.

**Type:** Gilda Display (titles on linen cards only), Hanken Grotesk (body, UI, headings on cloth), Pinyon Script (place-card names, scraps, sign-off).

**Signature moment:** setting the table. Eight place settings arrive one by one (plate settles with a small scale, cutlery slides in, wine glass pops), then three candles light and flicker down the runner. Hover or keyboard focus lifts the plate and the place card swaps its blurb for the latest real item. Places are real links; the two empty chairs jump to the guest book and focus the note box. Reduced motion shows the finished table.

**Motif:** plates, cutlery, candle glow, wine rings, hemmed cloth, folded place cards. Posters become plates; dishes with no photo get hand-drawn plate illustrations (three variants); empty rows get an empty plate.

**Light/dark:** one evening look, dark only. No light theme (a lit table at night is the point).

**Traps avoided (site-design section 3):** no cream+serif+clay (page is deep green, serif lives on linen only, accent is candlelight); no eyebrow caps labels; no identical card kit (movie plate-cards, dish menu lines, post invitations with seals, tilted note scraps differ); no gradient text; no side borders; no emoji as icons (emoji only as the guest's own mark); one signature animation, rows are static with hover only.

**With more time:** a horizontal long table on desktop; candle light cast onto plates; item detail pages reached from the plates; show more guest notes as handwritten scraps; a light "daytime" variant; skeleton for the form submit.
